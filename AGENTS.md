# Repository Instructions

## Branch naming

- Name feature branches `feature/YYMMDD-kebab-case-description`.
- Do not add a `codex/` prefix unless the user explicitly requests it.

## HACS test builds

- Publish test builds from a public branch in this repository.
- Give testers the full 40-character commit SHA for `update.install` so the
  installed build is immutable and reproducible.
